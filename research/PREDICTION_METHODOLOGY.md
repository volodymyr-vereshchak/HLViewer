# Прогнозирование часового потребления газа населением

## Основной скрипт

`backend/hourly_tri_regime_cv.py` — трёхрежимная модель с часовым профилем.

Зависимость: `backend/data_cleaning.py` — очистка аномалий.

## Архитектура модели

### Три температурных режима

Данные делятся на три режима в зависимости от температуры и сезона:

1. **ХОЛОД** (T < 15°C, не лето) — основной отопительный период
2. **ПЕРЕХОДНЫЙ** (T >= 15°C, не лето) — апрель-май, сентябрь-октябрь
3. **ЛЕТО** (июнь-август) — отдельная модель, т.к. потребление = 5-7% от зимнего

Порог 15°C выбран на основе scatter-анализа: все 7 ГРС показывают чёткий излом зависимости T-volume на этой температуре.

### Холод и переходный режимы: суточный предикт + часовой профиль

1. **Суточная агрегация**: часовые данные агрегируются в контрактные сутки (7:00-7:00)
2. **Признаки**:
   - Холод (24-31 признак): температура (mean/min/max/range/std), лаги (1-7 дней), скользящие средние, квадратичные, циклические (month_sin/cos, doy_sin/cos), давление (для линий с регуляторами)
   - Переходный (9-10 признаков): упрощённый набор из-за малого количества данных
3. **Модели**: автоматический подбор из RidgeCV, LassoCV, ElasticNetCV (alpha из logspace(-2, 4, 50), 5-fold CV)
4. **Часовой профиль**: суточный предикт распределяется по часам с помощью исторического профиля (доля каждого часа от суточного объёма), раздельно для холодного и переходного режимов

### Лето: 24 Ridge модели (по одной на час)

Для лета используется прямой часовой предикт — 24 отдельных RidgeCV моделей:

1. **Признаки** (7-8 на час): temperature, temp_lag_1h, temp_lag_3h, temp_ma_6h, temp_ma_24h, temp_diff_1h, is_weekend, [pressure]
2. **Outlier removal**: 3-sigma фильтр на обучающей выборке по каждому часу
3. **Константа для стабильных часов**: если mean < 10 м³ и CV < 0.25, предсказывается медиана (для ночных часов ГРС с маленьким потреблением)
4. **Агрегация**: часовые предикты суммируются в контрактные сутки для daily метрик

## Данные

- **Источник**: PostgreSQL (hourly_archive), погода (weather_2025_h.csv)
- **Предприятия**: вычитаются из общего объёма (volume_2025.xlsx), делятся на 24 часа
- **Виртуальные линии**: 1003 (Вільнянськ) = физ. [10,12], 1004 (Новомиколаївка) = физ. [14,15]
- **Исключение давления**: линии 16 (Димитрове) и 1003 (Вільнянськ) — нет регуляторов
- **Очистка**: hybrid-метод из data_cleaning.py (IQR + нулевые серии + спайки давления)

## Валидация

Monthly CV (leave-one-month-out): 12 фолдов, каждый месяц по очереди = тест.

### Проблемные сезоны

- **Май и Сентябрь** (переходные): MAPE 50-68% — высокая неопределённость при переходе отопление/лето
- **Сергіївка август**: аномальный кластер 2-12 августа (+30-40% объёма) — внешний фактор, не предсказуем по погоде
- **Тернівка июль**: экстремальные выбросы (50x от нормы) — предположительно аварийные/ремонтные ситуации

## Эволюция подходов

| # | Подход | R2_d отоп | MAPE отоп | MAPE лето |
|---|--------|:---------:|:---------:|:---------:|
| 1 | Единая линейная модель | 0.540 | 9.2% | — |
| 2 | Двухрежимная (cold/warm на 15°C) | 0.669 | 8.0% | — |
| 3 | Трёхрежимная + суточный предикт лета | 0.677 | 7.7% | 12.1% |
| 4 | **Трёхрежимная + 24xRidge для лета** | **0.677** | **7.7%** | **7.8%** |

### Что не сработало

- **SARIMAX, Prophet, Holt-Winters, LightGBM** без лагов потребления: в 3-4 раза хуже (MAE 258-375 м³ vs 83 м³)
- **Лаги давления в летней модели**: добавляли шум, ухудшали все линии кроме Сергіївки
- **Агрессивный CV-порог для константного предикта**: убивал температурный сигнал в хороших линиях
- **Единая модель на все температуры**: размывала паттерны разных режимов

### Ключевые инсайты

1. **Давление** — самый важный признак для зимы (по feature importance), для Сергіївки летом r=-0.636
2. **Регуляризация** (Ridge/Lasso) критична — без неё переобучение на малых выборках
3. **Раздельные режимы** дают +25% по R2 относительно единой модели
4. **Лето предсказуемо** (MAPE 3-8% для большинства ГРС), несмотря на отрицательный R2_daily (из-за low variance)
5. **Лаги потребления** могли бы значительно улучшить точность (ACF(24h)=0.94 для Сергіївки), но исключены по требованию

# Инструкция по прямому тестированию DPD API

## Назначение

Этот тест **НЕ использует ваш бекенд**. Он напрямую обращается к внешнему DPD API, чтобы проверить:

1. ✅ Какие поля реально возвращает DPD API
2. ✅ Есть ли в ответе `press` и `temper` (или `pressure` и `temperature`)
3. ✅ Различаются ли данные между предприятиями в самом API
4. ✅ Правильно ли работает аутентификация

## Подготовка

### 1. НЕ нужно запускать бекенд
Этот тест работает независимо от вашего бекенда

### 2. Убедитесь, что установлены библиотеки
```bash
pip install httpx
```

## Запуск теста

```bash
cd E:/HL/HLViewer/backend
python tests/test_dpd_api_direct.py
```

## Интерпретация результатов

### ✅ Если тест показывает:
```
✓ DPD API возвращает поля 'press' и 'temper'
✓ Данные различаются
```
**Вывод**: DPD API работает правильно, **НУЖНО ОБНОВИТЬ БЕКЕНД** с нашими исправлениями

### ⚠ Если тест показывает:
```
✗ Поле 'press' НЕ найдено
✗ Поле 'temper' НЕ найдено
✓ Поле 'pressure' найдено
✓ Поле 'temperature' найдено
```
**Вывод**: DPD API использует другие названия полей, нужно исправить бекенд по-другому

### ✗ Если тест показывает:
```
⚠ Все предприятия имеют ОДИНАКОВЫЙ объем
```
**Вывод**: Проблема в самом DPD API или в настройках устройств, НЕ в вашем бекенде

### ✗ Если тест показывает:
```
✗ Ошибка аутентификации
```
**Решение**: Проверьте учетные данные в `backend/core/config.py`:
```python
DPD_LOGIN = "ваш_логин"
DPD_PASSWORD = "ваш_пароль"
```

## Настройка теста

Откройте `tests/test_dpd_api_direct.py` и измените:

```python
TEST_ENTERPRISES_COUNT = 5  # Количество предприятий для анализа
```

Можно также вручную указать учетные данные в файле (если не работает импорт настроек):

```python
DPD_BASE_URL = "https://dpd.eco.zp.ua/api/v1/"
DPD_LOGIN = "ваш_логин"
DPD_PASSWORD = "ваш_пароль"
```

## Отличие от test_enterprise_poll.py

| Параметр | test_enterprise_poll.py | test_dpd_api_direct.py |
|----------|------------------------|------------------------|
| Что тестирует | Ваш бекенд API | Внешний DPD API напрямую |
| Нужен запущенный бекенд | ✓ Да | ✗ Нет |
| Показывает структуру данных | ✗ | ✓ Да (детально) |
| Проверяет маппинг полей | ✓ Да | ✗ |
| Назначение | Тест после обновления | Тест ПЕРЕД обновлением |

## Рекомендуемая последовательность

1. **Сначала** запустите `test_dpd_api_direct.py` (этот тест)
   - Узнайте какие поля возвращает DPD API
   - Проверьте различаются ли данные в источнике

2. **Потом** обновите бекенд на основе результатов

3. **Затем** запустите `test_enterprise_poll.py`
   - Проверьте что бекенд правильно обрабатывает данные

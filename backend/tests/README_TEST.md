# Инструкция по запуску тестов опроса предприятий

## Подготовка

### 1. Убедитесь, что бекенд запущен
```bash
cd E:/HL/HLViewer/backend
python -m uvicorn api.main:app --reload
```

Бекенд должен быть доступен по адресу `http://localhost:8000`

### 2. Установите необходимые библиотеки (если еще не установлены)
```bash
pip install httpx
```

## Запуск теста

### Способ 1: Запуск через Python напрямую
```bash
cd E:/HL/HLViewer/backend
python tests/test_enterprise_poll.py
```

### Способ 2: Через pytest (если установлен)
```bash
cd E:/HL/HLViewer/backend
pytest tests/test_enterprise_poll.py -v -s
```

## Настройка теста

Откройте файл `tests/test_enterprise_poll.py` и измените параметры:

```python
BASE_URL = "http://localhost:8000"  # URL вашего бекенда
TEST_ENTERPRISES_COUNT = 20  # Количество предприятий для теста
```

Вы можете изменить:
- **BASE_URL** - если бекенд запущен на другом порту или хосте
- **TEST_ENTERPRISES_COUNT** - количество предприятий для тестирования (по умолчанию 20)

## Что проверяет тест

1. **Получение списка предприятий** - тест запрашивает все предприятия из API
2. **Опрос каждого предприятия** - делает запрос для каждого из выбранных предприятий
3. **Проверка данных**:
   - Наличие записей за последние 7 дней
   - Проверка полей объема, температуры и давления
   - Сравнение объемов (выявление одинаковых значений)
4. **Вывод статистики**:
   - Количество успешных опросов
   - Количество предприятий без данных
   - Количество ошибок
   - Проверка актуальности данных

## Интерпретация результатов

### ✅ Хорошо
- Все предприятия опрошены успешно
- Данные различаются (объемы не одинаковые)
- Температура и давление заполнены для большинства записей

### ⚠ Внимание
- **Все объемы одинаковые** - возможно, бекенд не обновлен или используется кэш
- **Нет данных температуры/давления** - проблема с маппингом полей `press`/`temper`
- **Много предприятий без данных** - проблема с DPD API или неактивные устройства

### ✗ Проблема
- **Ошибки при опросе** - проблемы с API, сетью или неправильные параметры
- **Не удалось получить список предприятий** - бекенд не запущен или недоступен

## Устранение проблем

### Бекенд не запущен
```
✗ ОШИБКА при получении списка предприятий: ConnectError
```
**Решение**: Запустите бекенд

### Все объемы одинаковые
```
⚠ ВНИМАНИЕ: Все предприятия имеют одинаковый объем!
```
**Решение**:
1. Обновите бекенд с исправлениями
2. Перезапустите бекенд
3. Очистите кэш (если используется)

### Нет температуры/давления
```
✗ Температура: Нет
✗ Давление: Нет
```
**Решение**: Проверьте маппинг полей в `enterprise_ep.py`:
- Должно быть `record.get("temper")` вместо `record.get("temperature")`
- Должно быть `record.get("press")` вместо `record.get("pressure")`

## Дополнительные параметры

Для тестирования часовых данных измените в коде:
```python
period_type="hourly"  # вместо "daily"
```

Для изменения периода:
```python
from_date = to_date - timedelta(days=3)  # последние 3 дня
```

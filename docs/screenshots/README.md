# Скріншоти для документації

Імена мають збігатися зі шляхами, вказаними в `.md`-файлах.

- `6-1a-askcfg-format.png` — Приклад структури ask.cfg (ЛУМГ → Обчислювач → Лінії)
- `6-1b-cfg-mapping.png` — Шляхи даних: Конфіг імен, перегляд CFG, маппінг ЛУМГ

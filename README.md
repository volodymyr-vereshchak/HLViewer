# HLViewer

Система збору, обробки та перегляду архівних даних газовимірювальних приладів (обчислювачів
об'єму газу) по філіалах, ЛУМГ і лініях. Читає hostlib-архіви з мережевих шар, опитує об'єми
промисловості через DPD API і будує звіти (нічні витрати, годинні тренди, аварії тощо).
Керування — через веб-інтерфейс з адмін-панеллю.

## Стек

- **Бекенд:** FastAPI, SQLModel/SQLAlchemy (async), PostgreSQL, Alembic, APScheduler.
- **Фронтенд:** React + Vite (зібраний `dist` роздається через nginx).
- **Розгортання:** Docker Compose (Postgres + FastAPI + scheduler + фронтенд).
- **Автентифікація:** JWT у httpOnly-cookie, ролі `admin` / `viewer` з розмежуванням доступу
  до філіалів.

## Архітектура (коротко)

```
[Браузер] → nginx (фронтенд, :3001) → FastAPI (uvicorn, :8001) → PostgreSQL
                                       scheduler (APScheduler) ──┘   ↑
                                       DPD API (промисловість) ──────┘
Ієрархія даних:  Філіал → ЛУМГ → Обчислювач → Лінія
```

## Структура репозиторію (бекенд)

```
HLViewer/
├── backend/
│   ├── api/            # FastAPI: endpoints, middleware автентифікації, main.py
│   ├── db/             # моделі (SQLModel), DAO, alembic-міграції, engine.py
│   ├── hl_engine/      # бізнес-логіка: обробка hostlib-архівів, scheduler
│   └── settings.py     # конфігурація (читається з .env.v2)
├── tests/              # unit + integration тести
├── docs/               # ← документація (див. вище)
├── docker-compose.yml
└── requirements.txt
```
